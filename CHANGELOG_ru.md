# Changelog

## 2026-10-03

- Принят единый стандарт имён для документации в Trio, Peel и
  Monologue: английский `README.md` / `CHANGELOG.md`, русский
  `README_ru.md` / `CHANGELOG_ru.md`, с переключателем языка одной
  строкой в начале каждого файла (после бейджа лицензии, где он есть).
- Бейдж лицензии и раздел «Лицензия» приведены к британскому
  написанию (`licence` как существительное); сам файл остался
  называться `LICENSE`, его не трогали.
- Проверены `index.html`, `peel.html`, `monologue.html` и `cover.html`
  на русские комментарии разработчика в CSS/JS. Не найдено ни одного —
  вся кириллица во всех четырёх файлах это строки интерфейса внутри
  таблиц перевода RU/EN, что и есть правильное состояние, их не
  трогали.
